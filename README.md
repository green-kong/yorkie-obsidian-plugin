# 🐶 Yorkie Synkie: Real-Time Collaboration for Obsidian

## 🌟 Unleash the Power of Collaborative Note-Taking!

Yorkie Synkie brings the magic of real-time collaboration to your Obsidian vault. Powered by the robust Yorkie document store, this lightweight plugin transforms your solo note-taking experience into a vibrant, collaborative adventure!

### ✨ Key Features

- **🚀 Seamless Real-Time Collaboration**: Edit documents simultaneously with your team, watching changes appear instantly!
- **🔄 Automatic Conflict Resolution**: Say goodbye to merge conflicts. Yorkie Synkie handles it all behind the scenes.
- **🪶 Lightweight & Fast**: Designed for performance, it won't slow down your Obsidian experience.
- **🔌 Easy to Set Up**: Get started in minutes with our simple configuration process.

## 🛠️ Installation

1. Open Obsidian Settings
2. Navigate to Community Plugins and disable Safe Mode
3. Click on "Browse" and search for "Yorkie Synkie"
4. Install the plugin and enable it

## 🚀 Quick Start

### Starting Collaborative Editing
1. Create a new note or open an existing one.
2. Open the command palette (Command + P) and run the "Create Document Key" command.
	<img width="704" alt="image" src="https://github.com/user-attachments/assets/021bf438-1281-42e9-b11e-a887a3499462" />

3. Share the generated document key with those you want to collaborate with.
	<img width="469" alt="image" src="https://github.com/user-attachments/assets/af73a932-73eb-4329-b463-fb56be2f4abf" />

### Joining Collaborative Editing
1. Create a blank document. (Caution: Entering a key in a document with existing content may overwrite the previous content)
2. Open the command palette and run the "Enter Document Key" command.
	<img width="704" alt="image" src="https://github.com/user-attachments/assets/7e50ae12-0685-4ad9-b26d-d93534520594" />

3. Input the document key you received.

### Ending Collaborative Editing
1. Open the document you're collaboratively editing.
2. Open the command palette and run the "Remove Document Key" command.
	<img width="704" alt="image" src="https://github.com/user-attachments/assets/6453d41e-d9a7-4de2-b4cc-c05a73903db7" />

### Change User Name And Colour
1. Open the Yorkie Synkie settings tab.
2. Change user name and colour.

## 🐾 About Yorkie

[Yorkie](https://github.com/yorkie-team) is an open-source document store for building collaborative applications. It provides the backbone for Yorkie Synkie's real-time capabilities, ensuring smooth and efficient concurrent editing.
